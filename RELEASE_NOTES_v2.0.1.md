# Auralis v2.0.1

Full Auralis integration release.

- Product identity: **Auralis — Sound, Focus & Psychoacoustics**
- Application ID / package namespace: `com.marko.auralis`
- Internal Kotlin packages migrated to `com.marko.auralis`
- App/theme/service identifiers rebranded to Auralis
- New modern 2D stereo-wave launcher icon
- Auralis tagline integrated into the primary UI and About section
- WebView storage migrated from legacy keys to `auralis.v2.*` while preserving existing Auralis 2.0.0 data
- DSP algorithms, built-in preset values, safety behavior, Random Left/Right logic and double-Back behavior preserved
- Same signing identity retained for upgrade compatibility with Auralis 2.0.0
